# דירות של קדושה

לוח ניהול לדירות: תפוסה ולוח שנה, ניקיון, תקלות, הזמנות, תשלומים ותזרים חודשי.
האתר הוא דף סטטי (GitHub Pages). הנתונים וההתחברות נמצאים ב-Firebase.

## קבצים

| קובץ | מה יש בו |
|---|---|
| `index.html` | האתר עצמו |
| `fb.js` | החיבור ל-Firebase (התחברות ומסד נתונים) |
| `firebase-config.js` | פרטי הפרויקט ב-Firebase. אלה מזהים, לא סיסמאות |
| `firestore.rules` | חוקי האבטחה. מדביקים אותם ב-Firebase |
| `manifest.webmanifest`, `icon-*` | התקנה כאפליקציה במסך הבית |

## אבטחה

הנתונים מוגנים בשרת על ידי `firestore.rules`:
- **נתונים כספיים** (הזמנות, תשלומים, הוצאות, יומן): רק מנהלים יכולים לקרוא אותם.
- **איש ניקיון:** יכול לשנות רק את מצב הניקיון של דירה ולדווח על תקלות.
- **איש תחזוקה:** יכול לשנות רק את הסטטוס של תקלות.

אחרי כל שינוי בקובץ `firestore.rules` צריך להדביק אותו מחדש ב-Firebase:
Firestore Database ← Rules ← Publish.

## שמות משתמש

כל שם משתמש הופך לכתובת התחברות פנימית בדומיין של הפרויקט (`username@<project>.firebaseapp.com`).
לכתובות האלה לא נשלח אף פעם מייל.

את הקוד של משתמש אחר אי אפשר לאפס, כי זו מגבלה של המסלול החינמי של Firebase. מי ששכח את הקוד מקבל
"כניסה חדשה" מהמנהל, והכניסה הישנה מושבתת.
